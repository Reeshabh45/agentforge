## Getting Started

### Clone the Repository

```bash
git clone https://github.com/<username>/<repository>.git
```

### Install Dependencies

```bash
# Frontend
cd frontend
npm install

# Backend
cd ../backend
pip install -r requirements.txt
```

### Run the Application

```bash
# Frontend
npm run dev

# Backend
uvicorn app.main:app --reload
```
